# Sistema de Agendamento e Cálculo de IMC
Um site que gerencia consultas e calcula o Índice de Massa Corporal (IMC).
## Tecnologias Utilizadas:
- Node.js
- Express
- JSON
## Como executar o Projeto:
- 1. Clone o repositório:
```bash
git clone https://github.com/gabezinnnn/aula03_back_ex1.git
```
- 2. Abra a pasta com VS Code;
- 3. Abra o terminal do VS Code e instale as dependencias:
```cmd
npm init
npm install express
```
- 4. Inicie o arquivo:
```cmd
node server.js
```
- 5. Entre no link indicado por "Server".
